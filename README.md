# Attendance Management System

The Attendance Management System is a modern tool designed to automate the process of taking attendance in educational institutions. Traditional methods of attendance-taking can be time-consuming and prone to errors, leading to inaccurate records and unnecessary administrative burdens. This project addresses these challenges by utilizing face detection and Bluetooth technology to streamline attendance management.

## Key Features

- **Automated Attendance**: Leveraging face detection technology to identify students and mark their attendance automatically.
- **Bluetooth Integration**: Ensures that students within the classroom are detected, improving the accuracy of attendance records.
- **Database Storage**: All attendance data is securely stored in a database, providing easy access and analysis for authorized personnel.
- **User-Friendly Interface**: Simple and intuitive interface for managing attendance records, viewing reports, and analyzing trends.
